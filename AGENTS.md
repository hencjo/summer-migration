# Always

## Changelog

- Keep `# UNRELEASED` at the top of `CHANGELOG.md`.
- Group entries under `## Breaking changes`, `## Features and improvements`, `## Bug fixes`, or `## Chores`.
- Write entries as `* Description ([#123](https://github.com/hencjo/summer-migration/pull/123))`.
- Link to the relevant pull request or issue, never the commit.
